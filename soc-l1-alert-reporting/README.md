# SOC L1 Alert Reporting – Investigation Lab

This project documents my investigation and reporting process for the **SOC L1 Alert Reporting lab on TryHackMe**.

The lab simulates real Security Operations Center (SOC) tasks where analysts must:

- Investigate alerts
- Document findings
- Escalate incidents
- Communicate with higher-tier analysts

---

## Skills Demonstrated

• Security Alert Investigation  
• Phishing Email Analysis  
• Web Shell Detection  
• Incident Reporting  
• SOC Escalation Procedures  

---

## Investigations Included

| Investigation | Description |
|---------------|-------------|
| Phishing Email Investigation | Analysis of a spoofed Microsoft support email |
| Web Shell Investigation | Detection of suspicious processes on a server |
| Alert Escalation Process | Proper escalation workflow from L1 to L2 |

Lab completed on **TryHackMe – SOC Level 1 Path**
